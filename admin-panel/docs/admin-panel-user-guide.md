# Инструкция по админке World of Heels

## Как читать эту инструкцию
Документ написан простым языком и в правильном порядке действий.

Если коротко:
1. Сначала создаем основу (категория или карточка товара).
2. Потом создаем вариации (офферы).
3. Потом проверяем цены, фото, поля.
4. Только после проверки нажимаем Зберегти.

---

## Быстрый словарь (важные понятия)

### Ось
Ось - это параметр вариативности товара.

Примеры осей:
- Цвет
- Размер
- Высота каблука
- Материал

### Оффер
Оффер - это конкретный вариант товара с конкретной комбинацией осей.

Пример одного оффера:
- Цвет: Синий
- Каблук: 16 см
- Размер: 45

У каждого оффера свои:
- цена,
- SKU,
- фото,
- опции.

### Группа товара
Группа товара - это основная карточка товара.
Офферы находятся внутри группы.

### SKU
SKU (артикул) - уникальный код оффера для учета.

### Slug
Slug - часть URL (ссылка на товар/категорию).

## 1. Создание товара

## 1.1 Сначала заполняем общие поля товара
Сначала создается группа товара, а не офферы.

Заполните:
- Назва товару (UA)
- Назва товару (EN)
- Категорія (обязательно)
- Статус
- Підпис (UA/EN)
- Опис (UA/EN)

Важно:
- Без категории сохранить товар нельзя.
- Slug генерируется автоматически из UA-названия, но его можно менять вручную.

## 1.2 Автоперевод на EN
После заполнения UA-названий и описаний нажмите кнопку перевода.

Автозаполнение идет для:
- title.ua -> title.en
- subtitle.ua -> subtitle.en
- description.ua -> description.en

После перевода обязательно проверьте EN вручную.

## 1.3 Массовая генерация офферов через модалку
В карточке товара нажмите кнопку массовой генерации (иконка слоев).

В модалке 2 шага:
1. Шаг выбора характеристик (осей и значений).
2. Шаг цен для созданных комбинаций.

Что делает система:
- строит все комбинации выбранных значений,
- не создает дубликаты уже существующих комбинаций,
- генерирует SKU для новых офферов автоматически.

## 1.4 Как применить цену ко всем офферам
На шаге цен:
1. Введите значение в поле Ціна для всіх офферів.
2. Нажмите Застосувати до всіх.
3. При необходимости исправьте отдельные офферы вручную.

## 1.5 Обязательные поля (важно)

Обязательные поля карточки товара:
- slug
- title.ua
- title.en
- categoryIds (хотя бы 1 категория)
- status
- subtitle.ua
- subtitle.en
- description.ua
- description.en

Обязательные поля оффера:
- price
- sku

Если эти поля не заполнены, форма не сохранится.

## 1.6 Аксессуар для всех офферов
Есть отдельное поле: Аксесуар для всіх офферів.

Как работает:
1. Сначала должны существовать офферы.
2. Выбираете один аксессуар.
3. Он применяется ко всем офферам сразу.

Также у каждого оффера есть индивидуальное поле аксессуара.

## 1.7 Размерная сетка
В блоке Розмірна сітка можно:
- загрузить картинку файлом,
- либо вставить URL вручную.

## 1.8 Заполнение полей в самих офферах
Для каждого оффера проверьте:
- цену,
- SKU,
- аксессуар,
- значения осей,
- фото.

## 1.9 Артикулы (SKU)
- SKU генерируется автоматически, если поле пустое.
- При необходимости можно изменить вручную.

## 1.10 Очень важная логика фото в офферах
Когда вы добавляете фото в один оффер, система может автоматически проставить его в другие офферы с тем же кластером осей.

Простыми словами:
- если совпадают общие оси,
- а отличается только ось варианта изображения,
- фото подтягивается в эти офферы автоматически.

Ваш пример (Синий + Каблук 16 + Размер 45) отражает реальную логику:
- фото обычно распространяется на соседние размеры внутри той же связки общих осей.

Важно:
- если у оффера уже есть фото, оно не перезаписывается автоматически.

## 1.11 Фильтр офферов
Над списком офферов есть фильтры по осям.

Зачем это нужно:
- быстро увидеть только нужную группу офферов,
- удобно проверять цены/фото/опции в большом списке.

## 2. Создание категорий

## 2.1 Как создать родительскую категорию
1. Откройте Категории.
2. Нажмите Додати.
3. Заполните основные поля.
4. В поле Батьківська категорія оставьте Без батьківської (коренева).
5. Нажмите Зберегти.

## 2.2 Какие поля у категории заполнять
Основные поля:
- Назва категорії (UA) - обязательно
- Назва категорії (EN)
- Slug - обязательно
- Статус - обязательно
- Опис (UA/EN)
- Батьківська категорія (для дочерней)

## 2.3 Офферы в категории (через шаблон осей)
У категории есть блок настройки осей вариаций (variationTemplate):
- добавляете оси,
- задаете тип оси (select/number),
- задаете значения.

Это важно, потому что:
- при создании товара выбранная категория передает товару шаблон осей,
- массовая генерация офферов берет значения из этого шаблона.

Важно для дочерних категорий:
- шаблон осей может быть заблокирован для редактирования,
- тогда используется шаблон корневой категории ветки.

## 3. Склад

Раздел Склад нужен для работы с остатками.

Что можно делать:
- видеть остатки по товарам и складам,
- включать режим редактирования залишків,
- вносить фактические количества,
- массово применить изменения кнопкой Застосувати.

Простой порядок:
1. Нажмите Редагування залишків.
2. Внесите значения.
3. Нажмите Застосувати.

## 4. Клиенты

Раздел Клієнти:
- просмотр списка,
- поиск,
- открытие карточки,
- редактирование данных клиента,
- экспорт CSV.

В карточке клиента обычно редактируются:
- статус,
- роль,
- контакты,
- адрес доставки.

## 5. Контент

Раздел Контент - это точка входа в контентные сущности.

В текущей конфигурации:
- основной рабочий пункт в этом блоке - Банери.

Базовый процесс:
1. Открыть Контент.
2. Перейти в нужный контентный тип.
3. Открыть запись.
4. Отредактировать и сохранить.

## 6. Отзывы

Раздел Відгуки:
- список отзывов,
- фильтры и сортировка,
- создание/редактирование отзыва,
- привязка отзыва к товару,
- рейтинг,
- текст,
- статус,
- флаги показа (на товаре / на главной),
- экспорт.

## 7. Заказы

Раздел Заказы:
- поиск и фильтрация,
- открытие карточки,

- добавление товара в заказ через модалку,
- изменение количества,
- данные покупателя,
- доставка,

## Мини-чеклист перед сохранением товара

- Категория выбрана
- UA/EN поля заполнены
- Офферы созданы
- Цены заполнены
- SKU проверены
- Фото проверены
- Аксессуар применен (если нужен)
- Размерная сетка добавлена (если нужна)

## Частые ошибки

### Ошибка: товар не сохраняется
Причина: пустое обязательное поле.
Что делать: проверьте обязательные поля группы и цену/SKU у офферов.

### Ошибка: не работает аксессуар для всех
Причина: офферы еще не созданы.
Что делать: сначала создайте офферы.

### Ошибка: фото разошлось не так, как ожидали
Причина: неверно понята логика осей.
Что делать: проверьте, какие оси одинаковые в группе, и где уже есть фото.

### Ошибка: слишком много офферов после генерации
Причина: выбрано слишком много значений по осям.
Что делать: генерируйте офферы этапами и сразу проверяйте результат.

---

## Рекомендуемый порядок работы (очень коротко)
1. Создать/проверить категорию и оси.
2. Создать карточку товара.
3. Нажать автоперевод.
4. Массово сгенерировать офферы.
5. Применить цену ко всем.
6. Проверить фото/SKU/опции.
7. Сохранить.
